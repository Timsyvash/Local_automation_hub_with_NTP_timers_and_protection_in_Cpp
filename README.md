# Local Automation Hub with NTP Timers and Protection in C++ (ESP8266)

Цей проєкт реалізує надійний локальний хаб автоматизації на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Система забезпечує точну синхронізацію часу через інтернет за протоколом **NTP** без використання додаткових апаратних годинників реального часу (RTC), а також працює на повністю неблокуючій архітектурі автоматів станів (FSM) із захистом від зависань та перезавантажень сторожовим таймером (Watchdog Timer).

---

## 🚀 Основні можливості

* **Неблокуюча архітектура (Finite State Machine - FSM)**: Розподіл логіки на стани (`CONNECTING`, `CONNECTED`, `NOT_CONNECTED`) із використанням функції `millis()`, що запобігає спрацьовуванню WDT-килимів і зависанням.
* **Синхронізація точного часу (NTP)**: Отримання часу з глобальних серверів точного часу (`pool.ntp.org`) з урахуванням часового поясу.
* **Автоматичне відновлення та таймаути**: 
  * Контроль підключення до Wi-Fi з обмеженням часу очікування (30 секунд) та безпечним перезавантаженням (`ESP.restart()`) у разі невдачі.
  * Автоматичне перепідключення (`WiFi.reconnect()`) у випадку втрати сигналу під час роботи.
* **Безпечне фонове оновлення**: Періодична синхронізація часу у фоновому режимі без зупинки основної програми.

---

## 🛠 Апаратне забезпечення та залежності

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Для роботи проєкту необхідні такі бібліотеки:
```ini
[env:wemos_d1_mini]
platform = espressif8266
board = d1_mini
framework = arduino
monitor_speed = 115200
lib_deps =
    taranais/NTPClient @ ^3.2.1
